Thirty-six keys carry the whole alphabet, every symbol, the numbers and all navigation. The remaining eighteen are a safety net. Every modifier sits under a resting finger, every layer is one thumb away, and the arrow keys are the same four keys Vim uses.

The short version. Fifty-four keys, thirty-six of which carry the entire system. Six layers, each reached by holding one thumb. Every modifier lives on the home row. What follows is every layer in full, the eight chords, the firmware settings that make it work, and the reasoning behind each decision — including what each one cost.

The reasoning

Nine decisions, and what each one costs

One idea holds the whole thing together: ← ↓ ↑ → live on h j k l. Not near them — on them. So the motion that moves the cursor in Vim also moves it in a browser, a file manager, a terminal pager and a text field, and the same four keys drive the pointer and the volume. Everything below either serves that, or pays for it.

Alphabet
QWERTY. Every optimised alternative scatters h j k l across the board, which turns each Vim motion into a mental transpose. Whatever they win in finger travel does not pay for that.
Home-row mods
CAGS. A/; Ctrl, S/L Alt, D/K Cmd, F/J Shift. Cmd is the most-pressed modifier on macOS, so it takes the middle finger rather than the weakest one; Ctrl takes the pinky, where the Caps-as-Ctrl habit already put it. Cost: this ordering is unusual enough that no diagram you find elsewhere will describe this board. That is what this page is for.
Chordal Hold
Enabled. Vial 0.7.4 ships it natively (QMK Settings → Tap-Hold). Same-hand mod+key is blocked, so df, dt, sd type as plain letters. This is the single change that makes QWERTY home-row mods survivable alongside Vim. Cost: see flag 01.
Escape
Left outer thumb only. No jk combo, no Caps-position duplicate. Clean break, fastest path to muscle memory.
NAV layer
Vim-augmented. Arrows stay on h j k l. The row below is spatially derived from them: line-start under ←, line-end under →, page-down under ↓, page-up under ↑. Word motions sit directly above. One spatial map, no lookup table.
Extra 18 keys
Conventional QWERTY overflow. Top row is a real number row; outer columns carry ` - [ ] ' Tab Ctrl Shift. Zero new muscle memory, and a bail-out on the days the layers feel like too much.
Layers
Six — NAV, MOUSE, MEDIA, SYM, NUM, FUN. Five hang off a thumb; MOUSE gave its thumb to Hyper. The numpad survives despite a real number row above it, because entering a column of figures across a row is miserable.
Hyper
Left inner thumb — tap Tab, hold Hyper (⌘⌃⌥⇧). Nothing in macOS binds all four modifiers, so every Hyper chord is exclusively yours. The thumb keeps its tap, so this costs no key — it costs a layer access: MOUSE gave up its hold and became a toggle behind FUN, on that same physical key.
Combos
Eight, all on the bottom row (plus Q+W). Two filters did the work: no home-row key, because a chord there fights the tap-hold decision every time; and no pair you actually type, which disqualifies the whole QWERTY top row. Brackets mirror finger-for-finger across both hands.

Twelve chords

Combos

Two constraints, and together they eliminate almost everywhere a combo could go. One: nothing on the home row, or the chord races a home-row mod’s tap-hold timer. Two: nothing on a sequence you actually type — which rules out the whole top row, because QWERTY packs we, er, rt, io and op into adjacent keys. What survives is the bottom row, which English barely rolls, plus Q+W, a pair no English word contains.

Vial · QMK Settings

Firmware configuration

All eight ship inside the layout file — loading it sets the Tap-Hold panel in one go. Listed here because two of them are load-bearing: without Chordal Hold and Flow Tap, home-row modifiers on QWERTY are not merely imperfect, they are unusable.

SettingValueReason
Chordal HoldonBilateral combinations. A mod-tap only holds when the other key is on the opposite half — which is what lets df, dt and sd type as plain letters.
Flow Tap150 msSuppresses holds during a fast typing streak. Same problem as above, attacked from time-between-keys rather than handedness; the two together are belt and braces.
Tapping term170 msOne global value. With the two settings above doing the real work, per-finger terms stop being necessary.
Permissive HoldonLets a fast intentional mod register without waiting out the full term.
Hold On Other Key PressoffFights Permissive Hold on a home-row layout — it would resolve holds on any keypress, misfiring constantly.
Quick Tap Term120 msBackspace is a layer-hold, so holding it opens NUM instead of deleting. This is the escape hatch: tap, then press again within 120 ms and it repeats properly. At 0 you can never hold-delete.
Retro TappingoffRedundant here, and it makes a held-then-released mod emit a stray letter.
Combo term38 msTight enough that sequential typing never trips a chord.

The trade-offs

Six costs this layout accepts

01

Chordal Hold breaks same-hand Cmd shortcuts

⌘Q, ⌘W, ⌘A, ⌘S all live on the left hand, and Cmd is on left-hand D. Bilateral combinations block that. You must reach for the right Cmd (K) instead — which works fine, because the letter is on the left hand and the mod on the right. That is a real habit change, not a broken shortcut. Only ⌘Q gets a combo escape hatch, because quitting the wrong app hurts.

02

= and \ are layer-only

The outer column has four slots per hand and five candidates. - [ ' ] won; = and \ live on NUM. If you write more Go than prose, swap - for = on the right outer top.

03

The M+, chord sits on a real sequence

“…item m, next…” types M then comma. A 35–40 ms combo term makes this safe in practice, but it is the one chord in the set with a plausible collision. Watch it in week one.

04

The left-hand chords form an overlapping chain

Z+X, X+C, C+V and V+B each share a key with the next. QMK resolves on the exact set pressed, so X+C never fires Z+X — but rolling the bottom row fast could trip one. In practice you almost never roll zxcv; watch it anyway.

05

Hyper needs the thumb exemption, or half its chords vanish

Chordal Hold blocks same-hand mod+key. Hyper sits on the left thumb and most Hyper hotkeys land on the left hand — so without an exemption the firmware would silently swallow them. vimryoku-tuning.c exempts both thumb rows, which is safe because thumbs never appear in a typing roll. Flash that file if you use Hyper.

06

There is a two-to-six week dip

The alphabet costs nothing — the home-row mods and the six thumb layers are the whole adaptation. Expect 30–50% speed loss for the first week, most of it back by week three. The dip is the price of admission, not a sign the layout is wrong.

Configuration: siam-silakka54.vil loads the whole layout into Vial — seven layers, eight combos, all mod-taps. siam-silakka54-tuning.c adds the parts a .vil cannot carry: per-finger tapping terms and Chordal Hold handedness, both compile-time.
